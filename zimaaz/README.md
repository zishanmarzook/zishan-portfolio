# ZIMAAZ Thread Tales website

A responsive, single-page static website for the handmade baby and textile brand.

## Before launch

1. Replace each photo placeholder in `index.html` with an individual product image in `assets/` and update its accessible description.
2. Set `WHATSAPP_NUMBER` in the page script to the confirmed country-code-plus-number format (digits only). Until then, enquiry buttons fall back to the brand's Instagram profile.
3. Add product names, options, prices, delivery/payment terms, and care instructions only after the brand confirms them.

The page is buildless HTML/CSS/JavaScript and can be hosted on GitHub Pages.
